## 📖 About

PeriodicX is an open-source educational platform designed to make learning chemistry interactive, visual, and enjoyable.

Instead of simply displaying the periodic table, PeriodicX allows students to explore every one of the 118 chemical elements through detailed information, interactive flashcards, quizzes, atomic visualisations, and AI-powered explanations.

Whether you're preparing for school exams, exploring chemistry as a hobby, or teaching a classroom, PeriodicX aims to provide an intuitive and engaging learning experience.
